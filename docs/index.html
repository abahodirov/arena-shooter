Arena Shooter

A 3D wave-survival first-person shooter. Three arenas, three weapons, and an endless stack of soldiers and flying drones. Hold out as long as you can.

Download the game View source

Free · MIT licensed · Windows, macOS & Linux · Needs Python 3.9+

This is a desktop game, not a browser game. Ursina is built on Panda3D, which has no WebAssembly build, so Arena Shooter cannot run in a browser tab. Download it and run it locally — setup takes about a minute.

What's in it

A complete arena shooter in a single Python file.

🌊

Endless waves

Each wave adds another hostile, up to twelve at once, and enemy health scales as you climb. Clearing a wave pays a 250 × wave bonus and restocks your ammo.

🎯

Headshots matter

Headshots deal double damage and pay an extra 50 points. The end-of-run scoreboard tracks your kills, headshots and shot accuracy.

⚙️

Tuned to taste

Mouse sensitivity, field of view, volume, fullscreen and three difficulty levels — all saved between sessions, along with a personal best per arena.

🪙

Pickups

Fallen enemies drop coins worth 50 points and ammo crates worth 40 rounds for the Repeater. They vanish after 25 seconds, so go get them.

🤖

Two enemy types

Ground soldiers shoot from range and are worth 100 points each. Flying drones close in from above for 75.

📦

No build step

One dependency, one script. python fps_game.py installs the engine itself on first run if it is missing.

Three arenas

Each one changes how you have to fight.

Colosseum

A walled sand arena. Columns and stone blocks give you cover and the statue marks the centre. The forgiving one — nowhere to fall, plenty to hide behind.

Sky Garden

Floating grass islands above the clouds. Swarms of drones, no walls, and a long drop off every edge. Watch your footing more than your aim.

Downtown

A city block with a ring road and a fountain plaza. Long sight lines down the streets reward the Blaster and punish standing still.

How to play it

About a minute from here to the main menu.

  1. Install Python 3.9 or newer from python.org if you do not have it. On Windows, tick “Add Python to PATH” in the installer.
  2. Download the game and unzip it, or clone the repository with the commands below.
  3. Open a terminal in that folder and run the commands. Keep the assets folder next to fps_game.py.
# clone and launch
git clone https://github.com/abahodirov/arena-shooter.git
cd arena-shooter
pip install -r requirements.txt
python fps_game.py

The first launch downloads the Ursina engine and takes a minute; after that it starts straight away. You will need a GPU that supports OpenGL 3.2 or newer — anything from the last decade will do.
